IMAGE PLACEHOLDERS
==================

All files in this folder are placeholder images. Replace them with your real
photos before your site goes live — keep the same file names so nothing else
needs to change.

Recommended sizes:
  hero.svg                     1600 x 900   (or .jpg/.webp — update clinic-config.js)
  clinic-exterior.svg          1200 x 800
  reception.svg                1200 x 800
  treatment-room.svg           1200 x 800
  dentist.svg                   900 x 1100  (portrait)
  services/*.svg                900 x 700   (one per service)

To use a real photo:
  1. Save it with the SAME file name (e.g. images/dentist.svg -> dentist.jpg).
  2. If you change the extension (svg -> jpg), also update that path in
     clinic-config.js (IMAGES and SERVICES[].image).

Popular free photo sources if you don't have your own yet:
  Unsplash (unsplash.com), Pexels (pexels.com) — free to use.
  For a real local clinic, your own photos are always better for trust.
