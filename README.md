# 🦷 Dental Clinic Website (Fully Static)

A simple, modern, mobile-first website for a dental clinic. **No backend, no
database, no login, no paid services.** Just HTML, CSS (Tailwind), JavaScript
and images — deployable to any static host: Hostinger/cPanel, Vercel, Netlify,
GitHub Pages or Cloudflare Pages.

---

## Quick start

1. **Edit `clinic-config.js`** — this one file holds ALL of your site's content
   (clinic name, doctor, address, phone, WhatsApp, services, FAQs, reviews,
   timings, links, images). Every field is explained with comments.
2. **Replace the placeholder images** in the `images/` folder with your real
   photos (same file names — done).
3. **Preview locally** — just open `index.html` in a browser (double-click).
   Everything works from the file system; no server needed.
4. **Start over?** Run `npm install` once, then `npm run build` whenever you
   change code. (You only need this if you touch HTML/CSS/JS. Content edits in
   `clinic-config.js` need no build step.)

> The website itself is fully static — the `npm` step is only used on your
> computer to *pre-compile* the styling one time. Your hosted site runs with
> zero build commands.

## How the site works

- Every page loads `clinic-config.js` first, then `js/main.js`, which renders
  the header, footer, floating buttons, SEO tags, contact details and page
  content — all **from the config file**.
- Nothing clinic-specific is hard-coded in the HTML pages.
- SEO titles, meta descriptions, Open Graph tags and JSON-LD structured data
  are generated from `CLINIC_NAME`, `CITY`, services and FAQs automatically.

## Appointments — no backend needed

Two free options are built in, chosen in `clinic-config.js`:

| Option | How it works | Setup |
|--------|--------------|-------|
| **WhatsApp** (default) | The form opens WhatsApp with a pre-filled message (name, date, time, service, concern) | Just set `WHATSAPP_NUMBER`. Free, no setup. |
| **Static form** | The form POSTs to a free Formspree / Google Form address | Set `APPOINTMENT_METHOD: "form"` and add your form URL to `APPOINTMENT_FORM_ACTION_URL`. See `DEPLOYMENT.md` → "Form notifications". |

## Customising

| To change… | Edit… |
|------------|-------|
| Clinic name, phone, address, timings | `CLINIC_CONFIG` top section |
| Services shown on the site | the `SERVICES` array |
| FAQs, testimonials, why-choose-us | the matching arrays |
| Wording of the WhatsApp message | `WHATSAPP_BOOKING_TEMPLATE` |
| Images | files in `images/` |
| Colors / fonts / spacing | `css/input.css` → `npm run build` |
| Header links | the `NAV` array in `js/main.js` |

⚠️ **Reviews**: the config ships with clearly-labelled `Sample Patient`
testimonials. Replace them with real patient reviews (with permission) before
your site goes live — don't publish reviews that were never given.
